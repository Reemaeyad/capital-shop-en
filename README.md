  Capital Shop 🛍️

A modern and responsive fashion e-commerce website built using HTML5, CSS3, and JavaScript.

  📌 About the Project

Capital Shop is a modern online fashion store interface designed to provide users with a simple and attractive shopping experience.

The project includes product sections, categories, promotional content, latest news, and interactive product features.

 ✨ Features

- 🏠 Responsive Home Page
- 🛍️ Product Sections
- 👕 Trending This Week
- ❤️ You May Like
- 📰 Latest News
- 🛒 Add to Cart interaction
- ❤️ Wishlist interaction
- 👁️ Quick View
- 📱 Fully Responsive Design
- 🎨 Modern and clean UI
- 🖼️ Product and category images
- 🔗 Navigation between website sections

 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome / Icons
- Responsive Web Design
